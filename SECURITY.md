# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | -------------------- |
| latest  | :white_check_mark:   |
| < latest| :x:                  |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues.**

Instead, report them via:

- Email: security@blockyedu.org (to be configured)
- GitHub Security Advisory: submit via the Security tab of the affected repository

## What to Include

- Description of the vulnerability and its impact
- Steps to reproduce
- Affected versions
- Possible remediation suggestions (if any)

## Response Timeline

| Stage | Target |
| --- | --- |
| Acknowledgment | Within 48 hours |
| Initial assessment | Within 5 business days |
| Fix release | 7–30 days depending on severity |

## Scope

- All `blockyedu/*` repositories
- Official deployment environments
- CI/CD pipelines

## Out of Scope

- Known vulnerabilities in third-party dependencies (report upstream)
- Social engineering attacks
- Physical security

## Recognition

We appreciate responsible security researchers and will publicly acknowledge fixes (unless the reporter requests anonymity).
